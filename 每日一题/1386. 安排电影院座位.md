```c++
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {
        unordered_map<int,int> seats;
        for(auto& r:reservedSeats){
            int seat=r[1];
            if(2<=seat&&seat<=9){
                seats[r[0]] |=1<<seat;
            }
        }
  
        int empty=n-seats.size();
        int res=empty*2;
        for(auto& [_,x]:seats){
            if((x&0b111100)==0 ||(x&0b11110000)==0||(x&0b1111000000)==0){
                res++;
            }
        }
        return res;
    }
};
```

## 核心思想

使用**位掩码**记录每一行 `2~9` 号座位的预定情况。

由于 `seat` 本身可以直接作为 bit 的位置，因此对于预定座位 `seat`：
```
seats[row] |= 1 << seat;
```
将对应位置设为 `1`。
一家人可以坐的三个区域分别是：
```
2~5：0000111100
4~7：0011110000
6~9：1111000000
```
对于有预定座位的行，通过：
```
(x & mask) == 0
```
判断对应区域是否完全没有被占用。由于一行中 `2~9` 至少有一个座位被预定，因此这种行最多只能安排一个四人家庭，只要三个区域中有一个可用即可。
而没有 `2~9` 号预定座位的行，可以直接安排两个家庭。

## 复杂度分析
设 `m = reservedSeats.size()`。
- **时间复杂度：** `O(m)`
- **空间复杂度：** `O(m)`
其中哈希表只记录实际存在预定座位的行。

理解本题思想和做出这种类型的题，需要深度理解位运算，知道每种位运算，对实际比特位的影响，了解位掩码的思想。
