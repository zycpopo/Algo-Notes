## 暴力解法：
```c++
//时间复杂度O(n+q⋅n)，q为区间查询次数，即每次最坏O(n)
//空间复杂度O(n)
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n, a, b;
    cin >> n;
    vector<int> vec(n);
    for (int i = 0; i < n; i++) cin >> vec[i];
    while (cin >> a >> b) {
        int sum = 0;
        // 累加区间 a 到 b 的和
        for (int i = a; i <= b; i++) sum += vec[i];
        cout << sum << endl;
    }
}
```
## 前缀和解法：

前缀和解法常用于关于区间和的问题，核心思想很简单，单独创建一个数组p，p[i]就代表原数组下标0到i值得累加之和，![[Pasted image 20260721090607.png]]
现在计算区间和，就很简单了，举例计算下标3到下标5之间的区间和，用p[5]-p[2]计算就可以。
```c++
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n, a, b;
    cin >> n;
    vector<int> vec(n);
    vector<int> p(n);
    int presum = 0;
    for (int i = 0; i < n; i++) {
        cin >> vec[i];
        presum += vec[i];
        p[i] = presum;
    }

    while (cin >> a >> b) {
        int sum;
        if (a == 0) sum = p[b];
        else sum = p[b] - p[a - 1];
        cout << sum << endl;
    }
}
```

注意c++代码面对大量数据读取输出操作时，最好用scanf和print，耗时会小很多，这方面可以去搜索查解一下c和c++在输入输出的相关知识。
