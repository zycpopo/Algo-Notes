[18. 四数之和 - 力扣（LeetCode）](https://leetcode.cn/problems/4sum/description/)

## 标准基础写法：

```c++
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());
        for (int k = 0; k < nums.size(); k++) {
            // 剪枝处理
            if (nums[k] > target && nums[k] >= 0) {
            	break; // 这里使用break，统一通过最后的return返回
            }
            // 对nums[k]去重
            if (k > 0 && nums[k] == nums[k - 1]) {
                continue;
            }
            for (int i = k + 1; i < nums.size(); i++) {
                // 2级剪枝处理
                if (nums[k] + nums[i] > target && nums[k] + nums[i] >= 0) {
                    break;
                }

                // 对nums[i]去重
                if (i > k + 1 && nums[i] == nums[i - 1]) {
                    continue;
                }
                int left = i + 1;
                int right = nums.size() - 1;
                while (right > left) {
                    // nums[k] + nums[i] + nums[left] + nums[right] > target 会溢出
                    if ((long) nums[k] + nums[i] + nums[left] + nums[right] > target) {
                        right--;
                    // nums[k] + nums[i] + nums[left] + nums[right] < target 会溢出
                    } else if ((long) nums[k] + nums[i] + nums[left] + nums[right]  < target) {
                        left++;
                    } else {
                        result.push_back(vector<int>{nums[k], nums[i], nums[left], nums[right]});
                        // 对nums[left]和nums[right]去重
                        while (right > left && nums[right] == nums[right - 1]) right--;
                        while (right > left && nums[left] == nums[left + 1]) left++;

                        // 找到答案时，双指针同时收缩
                        right--;
                        left++;
                    }
                }

            }
        }
        return result;
    }
};


```

- 时间复杂度: O(n^3)
- 空间复杂度: O(1)

## 个人优化解法：
这个题和三数之和那道题的解法的核心思路一模一样，都是采用双指针的方法，个人在标准解法的基础上优化后的详细代码如下：
```c++
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> ret;
        sort(nums.begin(),nums.end());
  
        int n=nums.size();
        if(n<4) return ret;
        for(int i=0;i<n-3; ){
            long long sum1=(long long)nums[i]+nums[i+1]+nums[i+2]+nums[i+3];
            if(sum1 >(long long)target) break;
            
            long long sum2=(long long)nums[i]+nums[n-3]+nums[n-2]+nums[n-1];
            if(sum2 < (long long)target){
                i++;
                continue;
            }
  
            for(int j=i+1;j<n-2;)
            {
                long long sum3=(long long)nums[i]+nums[j]+nums[j+1]+nums[j+2];
                long long sum4=(long long)nums[i]+nums[j]+nums[n-1]+nums[n-2];
                if(sum3 > target) break;
                if(sum4 < target){
                    j++;
                    continue;
                }
            int left=j+1,right=n-1;
            long long currentTarget = (long long)target -nums[i]-nums[j];
  
            while(left < right){
                long long sum=nums[left] + nums[right];
  
                if(sum > currentTarget){
                    right--;
                }else if(sum < currentTarget){
                    left++;
                }else{
                    ret.push_back({nums[i],nums[j],nums[left],nums[right]});
                    left++,right--;
  
                    while(left<right && nums[left]==nums[left-1]) left++;
                    while(left<right && nums[right]==nums[right+1]) right--;
                }
            }
            j++;
            while(j<n-2&&nums[j]==nums[j-1]) j++;
            }
        i++;
        while(i<n-2&&nums[i]==nums[i-1]) i++;
        }
        return ret;
    }
};
```

- **时间复杂度**：O(n³)，排序 O(n log n) + 双重循环 + 双指针
- **空间复杂度**：O(1)，仅结果数组
我的写法是在基础版的前提下做了优化，思路大概就是排序 + 双重循环 + 双指针。在三数之和基础上多套一层循环，同时利用排序做**双向剪枝**减少搜索空间。

**解题步骤如下**：
1. **排序**：先对整个数组排序，使相同元素相邻，方便后续去重和剪枝
2. **外层循环固定 `i`**：遍历 `i` 从 `0` 到 `n-4`，作为四元组的第一个数。
3. **`i` 层剪枝**：
    - 计算以 `i` 为起点的**最小四数和**（`nums[i]+nums[i+1]+nums[i+2]+nums[i+3]`），若大于 `target`，说明后续所有组合都更大，直接结束整个循环。
    - 计算以 `i` 为起点的**最大四数和**（`nums[i]+nums[n-3]+nums[n-2]+nums[n-1]`），若小于 `target`，说明当前 `i` 不可能构成解，`i` 后移。
4. **中层循环固定 `j`**：遍历 `j` 从 `i+1` 到 `n-3`，作为四元组的第二个数。
5. **`j` 层剪枝**：与 `i` 层同理，用当前 `j` 的最小四数和与最大四数和判断，提前跳过无效区间。
6. **双指针找剩余两数**：
    - 目标值转化为两数之和：`need = target - nums[i] - nums[j]`。
    - 左指针 `left` 从 `j+1` 出发，右指针 `right` 从数组末尾出发。
    - 若 `nums[left] + nums[right] > need`，说明右数太大，`right` 左移。
    - 若 `nums[left] + nums[right] < need`，说明左数太小，`left` 右移。
    - 若相等，则找到一组解，加入结果，然后对 `left` 和 `right` 分别去重后同时收缩
7. **`j` 去重**：`j` 循环结束后，跳过与当前 `nums[j]` 重复的值。
8. **`i` 去重**：`i` 循环结束后，跳过与当前 `nums[i]` 重复的值。
9. **返回结果**：所有有效组合收集完毕，返回结果数组。
