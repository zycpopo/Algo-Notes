[454. 四数相加 II - 力扣（LeetCode）](https://leetcode.cn/problems/4sum-ii/description/)

## 哈希解法：
这道题我们可以将四个数分成两组，分别加起来然后，最后在借助map，找出符合相加为0条件的组数。
```c++
class Solution {
public:
    int fourSumCount(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3, vector<int>& nums4) {
        unordered_map<int,int> ump;
        for(int a:nums1){
            for(int b:nums2){
                ump[a+b]++;
            }
        }
        int count=0;
        for(int c:nums3){
            for(int d:nums4){
                if(ump.find(0-(c+d))!=ump.end()){
                    count+=ump[0 - (c + d)];
                }
            }
        }
        return count;
    }
};
```
- 时间复杂度: O(n^2)
- 空间复杂度: O(n^2)
解题步骤：
1. 首先定义 一个unordered_map，key放a和b两数之和，value 放a和b两数之和出现的次数。 遍历大A和大B数组，统计两个数组元素之和，和出现的次数，放到map中。
2. 定义int变量count，用来统计 a+b+c+d = 0 出现的次数。
3. 再遍历大C和大D数组，找到如果 0-(c+d) 在map中出现过的话，就用count把map中key对的value也就是出现次数统计出来。
4. 最后返回统计值 count 就可以了。
