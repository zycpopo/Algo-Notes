[349. 两个数组的交集 - 力扣（LeetCode）](https://leetcode.cn/problems/intersection-of-two-arrays/description/)
## 暴力数组法：
```c++
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        int hash1[1001]={0};
        int hash2[1001]={0};
        for(auto x:nums1){
            if(hash1[x]==0){
                hash1[x]++;
            }
        }
        for(auto x:nums2){
            if(hash2[x]==0){
                hash2[x]++;
            }
        }
        int hash3[1001]={0};
        for(int i=0;i<1001;i++){
            hash3[i]=hash1[i]+hash2[i];
        }
        vector<int> result;
        for(int i=0;i<1001;i++){
            if(hash3[i]>1){
                result.push_back(i);
            }
        }
        return result;
    }
};
```

本人写的这个解法非常low，虽然时间复杂度和空间复杂度是O(n+m)和O(1)，但这只是因为题目提供了数据范围，如果没有给出明确的数据范围的时候还是建议使用unordered_set比较好，尤其是数据范围较大时。

## unordered_set优化版：
```c++
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
	    unordered_set result;
	    unordered_set nums(nums.begin(),nums.end());
	    for(int x:nums2){
		    if(nums.find(x)!=nums.end()){
				result.insert(x);	
		    }
	    }
	    return vector<int>(result.begin(),result.end());
    }
};
```
这个解法就是关于这个题的优解版，不过这道题修改后，更新了数据范围调整，所以还可以使用厦门的半优解版，下面的解法是对第一个·的优化写法：:

```c++

```

这种解法和上一个的区别在此，时间复杂度都为O(n+m)，但是空间复杂度第一个是O(n+k),第二个是O(k)。
### 总结如何选择：
**场景**                                             **推荐**
**数据范围小且已知**（如 0~1000） | 第一个：数组标记更省空间，时间一样           |
**数据范围大或未知**                         | 第二段：`unordered_set` 更通用、更简洁      |
**追求代码简洁**                                | 第二段                                                          |
**极致省空间**                                   | 第一段（但牺牲通用性）                               |
