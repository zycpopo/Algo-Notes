[151. 反转字符串中的单词 - 力扣（LeetCode）](https://leetcode.cn/problems/reverse-words-in-a-string/description/)

## 标准解法：
```c++
class Solution {
public:
    // 翻转字符串指定区间 [start, end]，左闭右闭
    void reverse(string& s, int start, int end) {
        for (int i = start, j = end; i < j; i++, j--) {
            swap(s[i], s[j]);
        }
    }
    
    // 去除多余空格：前导、后导、中间连续空格只保留一个
    void removeExtraSpaces(string& s) {
        int slow = 0;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] != ' ') {  // 遇到非空格，说明是单词开头
                // 不是第一个单词时，先补一个空格
                if (slow != 0) s[slow++] = ' ';
                // 把整个单词搬过来
                while (i < s.size() && s[i] != ' ') {
                    s[slow++] = s[i++];
                }
            }
        }
        s.resize(slow);  // 截断多余部分
    }
    
    string reverseWords(string s) {
        // 第一步：去多余空格
        removeExtraSpaces(s);
        
        // 第二步：整体翻转
        reverse(s, 0, s.size() - 1);
        
        // 第三步：逐个单词翻转
        int start = 0;
        for (int i = 0; i <= s.size(); ++i) {
            // 遇到空格或到达末尾，说明找到了一个单词边界
            if (i == s.size() || s[i] == ' ') {
                reverse(s, start, i - 1);  // 翻转这个单词
                start = i + 1;             // 下一个单词的起始位置
            }
        }
        return s;
    }
};
```
- **时间复杂度：** O(n)  
    去空格、整体翻转、单词翻转，各遍历一遍字符串，总体线性。
- **空间复杂度：** O(1)  
    原地操作，未使用额外数组（如果算上 `string` 内部扩容，则是 O(n) ，但算法本身只用常数指针）。

## 解题总结：
1. **双指针去空格**：`slow` 指针负责构建新字符串，`i` 指针负责遍历原字符串，跳过所有空格，只在单词之间保留一个空格。
2. **先扩后翻**：先整体翻转，再局部翻转，是字符串单词翻转的经典套路。
3. **注意边界**：`for (int i = 0; i <= s.size(); ++i)` 这里用 `<=` 是为了让 `i == s.size()` 时能触发最后一个单词的翻转。
这道题是字符串操作的「模板题」，掌握「双指针去空格 + 两次翻转」的套路后，很多字符串处理题都能举一反三。

这个题最主要的部分就是移除多余空格，核心算法原理和那道”移除元素“一样，采用快慢指针的方式移除多余空格，这里我重新将此部分写一遍。
