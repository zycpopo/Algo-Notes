[54. 替换数字（第八期模拟笔试） (kamacoder.com)](https://kamacoder.com/problempage.php?pid=1064)

## 标准解法：
 ```c++
#include <iostream>
using namespace std;

int main() {
    string s;
    while (cin >> s) {
        int sOldIndex = s.size() - 1;
        int count = 0; // 统计数字的个数
        for (int i = 0; i < s.size(); i++) {
            if (s[i] >= '0' && s[i] <= '9') 
                count++;
            }
        }
        // 扩充字符串s的大小，也就是将每数字替换成"number"之后的大小
        s.resize(s.size() + count * 5);
        int sNewIndex = s.size() - 1;
        // 从后往前将数字替换为"number"
        while (sOldIndex >= 0) {
            if (s[sOldIndex] >= '0' && s[sOldIndex] <= '9') {
                s[sNewIndex--] = 'r';
                s[sNewIndex--] = 'e';
                s[sNewIndex--] = 'b';
                s[sNewIndex--] = 'm';
                s[sNewIndex--] = 'u';
                s[sNewIndex--] = 'n';
            } else {

                s[sNewIndex--] = s[sOldIndex];
            }
            sOldIndex--;
        }
       cout << s << endl;      
    }
}

 ```
- **时间复杂度：** O(n) ，遍历两遍字符串（第一遍统计，第二遍填充）
    
- **空间复杂度：** O(1) 额外空间（原地扩容，未使用辅助数组）


 ## 思路分析：
### 为什么不能从左往右直接替换？

如果直接从左往右遍历，遇到一个数字就插入 `"number"`，会导致**后续字符被覆盖或需要频繁移动元素**，时间复杂度变成 O(n2) 。

### 正确思路：先扩容，再从后往前填充

1. **先统计数字个数** `count`  
    每个数字要替换成 `"number"`（共 6 个字符），原来只占 1 个字符，所以每遇到一个数字，字符串需要**额外增加 5 个位置**。
2. **扩容字符串**  
    `s.resize(s.size() + count * 5)
3. **双指针从后往前填充**
    - `sOldIndex`：指向原字符串的末尾（未扩容前的最后一个字符）
    - `sNewIndex`：指向扩容后字符串的末尾
    从后往前遍历的好处是：**新写入的字符不会覆盖还未处理的旧字符**
4. **替换规则*
    - 若 `s[sOldIndex]` 是数字，则在 `sNewIndex` 位置从后往前依次写入 `'r','e','b','m','u','n'`（倒序写入，正序看就是 `"number"`
    - 若不是数字，直接复制该字符
## 重要点！

| 要点                           | 说明                                                                |
| :--------------------------- | :---------------------------------------------------------------- |
| **为什么要 `count * 5`？**        | `"number"` 长度为 6，原数字占 1 位，净增 6−1=5 位                              |
| **为什么要从后往前？**                | 防止新写入的 `"number"` 覆盖还没遍历到的旧字符                                     |
| **字母为什么是倒着写的？**              | 因为指针 `sNewIndex` 是从高索引往低索引移动的，先写 `'r'` 放在高位，最终字符串里就是正序 `"number"` |
| **为什么用 `while (cin >> s)`？** | 卡码网/某些 OJ 平台可能有多组测试数据，持续读到文件结束                                    |
