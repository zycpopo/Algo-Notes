[28. 找出字符串中第一个匹配项的下标 - 力扣（LeetCode）](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/description/)

## KMP算法
## 1. 问题

在字符串 `text` 里找 `pattern`。暴力法是失配后 `text` 回退重来，最坏 $O(nm)$。
## 2. 核心洞察

失配时，`text` 前面已经匹配的部分**不需要重比**。只需要问：`pattern` 已匹配的部分里，有没有一段**前缀**刚好能接上下一个字符？
## 3. next 数组（前缀表）

`next[i]` = 子串 `pattern[0..i]` 的**最长相等前后缀长度**。

```
pattern:  a  b  a  b  c  a  b  a  b  a  b
next:     0  0  1  2  0  1  2  3  4  3  4
```
## 4. 匹配时怎么用

```
text:    a b a b a b c a b c
pattern: a b a b c
              ↑
            j=4 失配('a'≠'c')
            
回退: j = next[3] = 2
pattern:     a b a b c
                ↑
              j=2 继续比('a'=='a')
```

**主串 `i` 永不回退，只有 `j` 跳。**
## 5. 代码骨架

```cpp
// 算 next
for (int i = 1, j = 0; i < m; i++) {
    while (j > 0 && p[i] != p[j]) j = next[j-1];
    if (p[i] == p[j]) j++;
    next[i] = j;
}

// 匹配
for (int i = 0, j = 0; i < n; i++) {
    while (j > 0 && t[i] != p[j]) j = next[j-1];
    if (t[i] == p[j]) j++;
    if (j == m) return i - m + 1;
}
```
## 6. 复杂度

- 时间：$O(n + m)$
- 空间：$O(m)$

**一句话**：KMP = 先给模式串算一本"失配自救指南"（next），匹配时主串只走一遍，失配就按指南跳，绝不回头。

---
## 7. 题目标准解法

```c++
class Solution {
public:
    void getNext(int* next, const string& s) {
        int j = 0;
        next[0] = 0;
        for(int i = 1; i < s.size(); i++) {
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }
            if (s[i] == s[j]) {
                j++;
            }
            next[i] = j;
        }
    }
    int strStr(string haystack, string needle) {
        if (needle.size() == 0) {
            return 0;
        }
        vector<int> next(needle.size());
        getNext(&next[0], needle);
        int j = 0;
        for (int i = 0; i < haystack.size(); i++) {
            while(j > 0 && haystack[i] != needle[j]) {
                j = next[j - 1];
            }
            if (haystack[i] == needle[j]) {
                j++;
            }
            if (j == needle.size() ) {
                return (i - needle.size() + 1);
            }
        }
        return -1;
    }
};
```
### 时间复杂度

|     | 暴力              | KMP        |
| --- | --------------- | ---------- |
| 时间  | $O(n \times m)$ | $O(n + m)$ |
| 空间  | $O(1)$          | $O(m)$     |
- `getNext` 遍历一遍模式串，O(m)
- `strStr` 遍历一遍主串，O(n)
- `next` 数组占用 O(m) 额外空间

题目中获取next数组方式就是直接照搬前缀表，对前缀表不产生任何变化。这个题的主要还是对KMP算法有一个完整的理解，懂前缀表的意义和next数组在代码中的变化。如果还是不能理解，把前面关于KMP算法的讲解好好看一下。
