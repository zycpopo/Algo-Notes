[459. 重复的子字符串 - 力扣（LeetCode）](https://leetcode.cn/problems/repeated-substring-pattern/description/)

# 1. 标准题解

```c++
class Solution {
public:
    void getnext(int* next,const string s){
        int j=0;
        next[0]=0;
        for(int i=1;i<s.size();i++){
            while(j>0 && s[j]!=s[i]){
                j=next[j-1];    
            }
            if(s[i] == s[j]){
                j++;
            }
            next[i]=j;
        }
    }
    bool repeatedSubstringPattern(string s) {
        vector<int> next(s.size());
        getnext(&next[0],s);
        int lps=next[s.size()-1];
        if (lps == 0) return false;
        int p=s.size()-lps;
        return s.size() % p == 0;
    }
};
```
- 时间复杂度：O(n)
- 空间复杂度：O(n)
此题依旧考察的是关于KMP算法的题目
## 思路：KMP 前缀表

### 核心洞察
如果 `s` 能由某个子串重复构成，那么 `s` 一定有一个**非平凡的相等前后缀**。
例如 `"abab"`：
- 前缀 `"ab"` = 后缀 `"ab"`
- 最长相等前后缀长度 `lps = 2`

```plain
s = "abab"
      ↑___↑
      前后缀相等，长度 2
```

### 关键推导
设：
- `len` = 字符串总长度
- `lps` = 最长相等前后缀长度

```plain
最小重复子串长度 = len - lps
```
如果 `len % (len - lps) == 0`，说明总长度刚好是整数个周期。
```plain
"abab": len=4, lps=2, 周期=4-2=2, 4%2==0 → true
"aba":  len=3, lps=1, 周期=3-1=2, 3%2==1 → false
```

### 为什么？
如果 `s` 由子串 `t` 重复 `k` 次构成：
```plain
s = t t t ... t
```
那么去掉最后一个 `t`，剩下的 `len - |t|` 个字符既是前缀也是后缀，所以 `lps = len - |t|`。
反过来，`len - lps = |t|` 就是周期长度。能整除就说明凑齐了。

# 2. 拼接法
根据这个原理我们还能得到一个巧妙的解法，代码如下：
```c++
bool repeatedSubstringPattern(string s) {
    string t = s + s;           // "abab" → "abababab"
    t = t.substr(1, t.size() - 2);  // 掐头去尾 → "bababa"
    return t.find(s) != string::npos;  // 中间还能找到原串？
}
```
- 时间复杂度：O(n)
- 空间复杂度：O(n)
