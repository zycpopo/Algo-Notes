[344. 反转字符串 - 力扣（LeetCode）](https://leetcode.cn/problems/reverse-string/description/)

这个题非常简单，但是有一个问题就是我们该不该用reverse这个库函数，如果用了，这个题感觉没有任何意义了，虽然不用也特别简单，手动交换两个指针指向的元素就好了，但是我们必须注意好什么时候用库函数比较合适，什么时候用不合适。先看解题代码：

```c++
class Solution {
public:
    void reverseString(vector<char>& s) {
        if(s.empty()) return;
        size_t begin=0,end=s.size()-1;
        while(begin < end)
        {
            swap(s[begin++],s[end--]);
        }
    }
};
```

可以注意到我使用了swap这个库函数，那就有人要问了，为啥你不用reverse，但是又用swap。因为swap的实现原理简单而且我完全明白，所以我用了，但是reverse相当于破坏了这道题原本想要考察的内容。
并且如果库函数仅仅是 解题过程中的一小部分，并且你已经很清楚这个库函数的内部实现原理的话，可以考虑使用库函数。
本着这样的原则，我没有使用reverse库函数，而使用swap库函数。
