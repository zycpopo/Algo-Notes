[541. 反转字符串 II - 力扣（LeetCode）](https://leetcode.cn/problems/reverse-string-ii/description/)

## 个人解法：
```c++
class Solution {
public:
    string reverseStr(string s, int k) {
        int a=s.size();
        for(int i=0;i<a;i+=2*k)
        {
            reverse(s.begin()+i,s.begin()+min(i+k,a));
        }
        return s;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)

我的解法非常清晰易懂，唯一需要注意的边界条件，就是当剩余字符串不足2k但是大于或等于k，继续反转前k个字符串，所以每次反转的范围是 reverse(s.begin()+i,s.begin()+min(i+k,a));结尾是i+k和a的较小值，这部分就是为了处理上述的边界问题而提出的。
