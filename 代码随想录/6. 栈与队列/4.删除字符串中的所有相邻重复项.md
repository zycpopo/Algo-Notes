[1047. 删除字符串中的所有相邻重复项 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/description/)

## 我的解法：
```c++
class Solution {
public:
    string removeDuplicates(string s) {
        std::stack<char> st;
        for(int i=0;i<s.size();i++){
            if(st.empty() || s[i]!=st.top()){
                st.push(s[i]);
            }
            else if(s[i]==st.top()){
                st.pop();
            }
        }
        string result;
        while(!st.empty()){
            result.push_back(st.top());
            st.pop();
        }
        reverse(result.begin(),result.end());
        return result;
    }
};
```
- 时间复杂度: O(n)
- 空间复杂度: O(n)

## 字符串模拟栈解法：

```c++
class Solution {
public:
    string removeDuplicates(string s) {
        string st;
        for (char c : s) {
            if (!st.empty() && st.back() == c) st.pop_back();
            else st.push_back(c);
        }
        return st;  
    }
};
```
- 时间复杂度: O(n)
- 空间复杂度: O(1)，返回值不计空间复杂度

## 差异对比
|          | `stack<char>` 解法        | `string` 模拟栈                  |
| -------- | ----------------------- | ----------------------------- |
| **数据结构** | STL `stack`             | `string`（底层是连续数组）             |
| **栈顶操作** | `st.top()` + `st.pop()` | `st.back()` + `st.pop_back()` |
| **最后结果** | 需要倒出来 + `reverse`       | 直接就是正序，无需反转                   |
| **内存布局** | 不连续（通常 deque 实现）        | 连续数组                          |
| **代码行数** | 多 4~5 行（反转 + 拼接）        | 更简洁                           |
`string` 底层是连续内存，CPU 缓存命中率高；`stack` 基于 deque，指针跳转多。

两者都是 **O(n) 时间**，但 `string` 版本：
- 省去一次 O(n) 的 `reverse`
- `push_back`/`pop_back` 均摊 O(1)
- 实际运行更- 快
---
## 一句话总结

> **`stack` 是"真栈"，取出来的顺序天然反的，需要反转；`string` 是"假栈"，只在尾部模拟进出，整体顺序就是正序，一步到位。** 后者代码更短、更快、更优雅。
