[347. 前 K 个高频元素 - 力扣（LeetCode）](https://leetcode.cn/problems/top-k-frequent-elements/description/)

## 标准题解：
```c++
class Solution {
public:
    class mycomparison {
    public:
        bool operator()(const pair<int, int>& lhs, const pair<int, int>& rhs) {
            return lhs.second > rhs.second;  // 小顶堆：频率小的在堆顶
        }
    };
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        for (int num : nums) {
            freq[num]++;
        }
        priority_queue<pair<int, int>, vector<pair<int, int>>, mycomparison> pri_que;
        for (auto& it : freq) {
            pri_que.push(it);
            if (pri_que.size() > k) {
                pri_que.pop();  // 堆顶是第 k 大的，比它小的弹出
            }
        }
        vector<int> res(k);
        for (int i = k - 1; i >= 0; i--) {
            res[i] = pri_que.top().first;  // ← 修正：加上 .
            pri_que.pop();
        }
        return res;
    }
};
```
## 核心思路：**哈希计数 + 小顶堆**

### 第一步：统计频率

用 `unordered_map` 遍历数组，统计每个数字出现的次数。

```plain
nums: [1,1,1,2,2,3]
map:  {1:3, 2:2, 3:1}
```
### 第二步：维护大小为 K 的小顶堆

堆里存的是 `(数字, 频率)` 对，按频率排序——**频率小的在堆顶**。

遍历 map 时：
- 把当前元素 push 进堆
- 如果堆的大小超过 K，就把堆顶弹出

```plain
堆大小始终 ≤ K，堆顶是这 K 个里频率最小的（也就是全局第 K 大的）
```

这样遍历完，堆里剩下的就是频率最高的 K 个元素。
### 第三步：倒序取出结果

小顶堆的堆顶是第 K 大，所以从 `res[k-1]` 往前填，最终 `res` 就是频率从高到低。

## 为什么用小顶堆而不是大顶堆？

- **大顶堆**：需要把所有 n 个元素都压进去，再弹 K 次，堆的大小是 O(n)
- **小顶堆**：只维护 K 个元素，每次 push/pop 都是 O(log k)，更省空间
## 复杂度

- **时间**：O(n log k) —— 遍历 n 个元素，堆操作每次 O(log k)
- **空间**：O(n) —— 哈希表存频率

---
## 一句话总结

> **先数数，再用小顶堆"挤掉"频率低的，堆里始终只留 K 个最大的，最后倒出来就行。**
