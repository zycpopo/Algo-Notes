[232. 用栈实现队列 - 力扣（LeetCode）](https://leetcode.cn/problems/implement-queue-using-stacks/description/)

## 标准题解：
用两个栈实现队列，一个输入栈，一个输出栈。代码如下：
```c++
class MyQueue {
private:
    stack<int>stack1;
    stack<int>stack2;
public:
    MyQueue() {
    }
    void push(int x) {
        stack1.push(x);
    }
    int pop() {
        if(stack2.empty())
           while(!stack1.empty())
           {
                 stack2.push(stack1.top());
                 stack1.pop();
           }
  
        int front = stack2.top();
        stack2.pop();
        return front;
    }
    int peek() {
         if (stack2.empty())  
         {
            while (!stack1.empty())
            {
                stack2.push(stack1.top());
                stack1.pop();
            }
        }
        return stack2.top();
    }
    bool empty() {
        return stack1.empty() && stack2.empty();
    }
};
```
## 核心思路：**双栈倒序**

队列是 **FIFO**（先进先出），栈是 **LIFO**（后进先出），两者顺序相反。用两个栈配合，可以把顺序再倒回来。
### 两个栈的分工

|栈|作用|
|:--|:--|
|`stack1`（入队栈）|只负责 **push**，新元素直接往里塞|
|`stack2`（出队栈）|只负责 **pop/peek**，元素从这里出去|

### 关键操作：**"倒腾"**
当需要 `pop` 或 `peek` 时，如果 `stack2` 为空，就把 `stack1` 里的元素**全部倒过来**：
```plain
stack1: 底 [1, 2, 3] 顶
         ↓ 逐个弹出压入 stack2
stack2: 底 [3, 2, 1] 顶
```
倒完之后，`stack2` 的栈顶就是最早进入的元素（1），正好符合队列的队首。
### 为什么 `stack2` 非空时不倒？
因为 `stack2` 里剩下的元素**一定比 `stack1` 里的先入队**。如果中途倒，会破坏 FIFO 顺序。只有当 `stack2` 空了，才需要新一轮倒腾。
### 复杂度分析
- **push**: O(1)，直接压栈
- **pop/peek**: 均摊 O(1)。每个元素最多被倒腾两次（stack1→stack2→弹出），所以单次操作的均摊代价是常数。
- **empty**: O(1)
---
### 一句话总结

> **一个栈管进，一个栈管出；出栈空了，再把进栈的全倒过来。** 两次 LIFO 叠加，就变成了 FIFO。
