[20. 有效的括号 - 力扣（LeetCode）](https://leetcode.cn/problems/valid-parentheses/description/)

## 标准题解：

```c++
class Solution {
public:
    bool isValid(string s) {
        std::stack<char> st;
        if(s.size()%2 != 0){
            return false;
        }
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') st.push(')');
            else if (s[i] == '{') st.push('}');
            else if (s[i] == '[') st.push(']');
            // 第三种情况：遍历字符串匹配的过程中，栈已经为空了，没有匹配的字符了，说明右括号没有找到对应的左括号 return false
           // 第二种情况：遍历字符串匹配的过程中，发现栈里没有我们要匹配的字符。所以return false
            else if (st.empty() || st.top() != s[i]) return false;
            else st.pop(); // st.top() 与 s[i]相等，栈弹出元素
        }
        return st.empty();
    }
};
```

括号匹配的本质是 **"后开的先关"**——遇到左括号，要等它对应的右括号先匹配完，才能去管更外层的。这正是 **LIFO**，所以用栈。
### 匹配策略

遇到 **左括号**，不直接存它自己，而是存它**对应的右括号**。这样后面遇到右括号时，直接和栈顶比就行，省得再写映射表。
```plain
遇到 '(' → 栈 push ')'
遇到 '{' → 栈 push '}'
遇到 '[' → 栈 push ']'
```
遇到 **右括号** 时，只有两种情况能继续：
- 栈不空，且栈顶正好是这个右括号 → 匹配成功，弹出
- 否则 → 不匹配，直接 `false`
### 三个非法场景（代码里覆盖到了）

|场景|代码体现|例子|
|:--|:--|:--|
|左括号多了|遍历完栈不空|`"((("`|
|右括号多了/没匹配上|`st.empty()` 时遇到右括号|`")("`|
|类型不匹配|`st.top() != s[i]`|`"(]"`|

提前判断 `s.size() % 2 != 0` 是个小优化，奇数长度直接不可能匹配
### 复杂度
- 时间 O(n)：每个字符进栈出栈各一次
- 空间 O(n)：最坏全是左括号
--- 
### 一句话总结

> **左括号存对应的右括号，右括号来就和栈顶比。对得上就弹，对不上就错，最后栈必须空。**
