[203. 移除链表元素 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-linked-list-elements/description/)
## 1.直接操作

```c++
//时间复杂度: O(n)
//空间复杂度: O(1)
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        while(head!=NULL&&head->val==val){
            ListNode* tmp = head;
            head = head->next;
            delete tmp;
        }
        ListNode* cur = head;
        while(cur != NULL && cur->next!= NULL){
            if (cur->next->val == val) {
                ListNode* tmp = cur->next;
                cur->next = cur->next->next;
                delete tmp;
            } else {
                cur = cur->next;
            }
        }
        return head;
    }
};
```
这种方法要讨论两种情况，一个是目标是头节点，另外一种就是普通的解法。
## 2.虚拟头节点法
```c++
//时间复杂度: O(n)
//空间复杂度: O(1)
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        ListNode* dummy = new ListNode(0);
        dummy->next=head;
        ListNode* cur = dummy;
        while(cur->next != NULL&&cur !=NULL){
            if(cur->next->val == val){
                ListNode* tmp = cur->next;
                cur->next = cur->next->next;
                delete tmp;
            }
            else{
                 cur= cur->next;
            }
        }
        head = dummy->next;
        delete dummy;
        return head;
    }
};
```
这个解法创造出一个虚拟的头节点指向原本的head节点，这样子不管要删除的节点在哪里，都可以通过一个逻辑方式将它解决。
