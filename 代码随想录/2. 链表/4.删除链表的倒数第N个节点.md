[19. 删除链表的倒数第 N 个结点 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/)

## 双指针法
```c++
//时间复杂度: O(n)
//空间复杂度: O(1)
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;
        ListNode* slow = dummyHead
        ListNode* fast = dummyHead;
        
        while(n-- && fast != NULL) {
            fast = fast->next;
        }
        fast = fast->next;
        
        while(fast!=NULL){
            fast = fast->next;
            slow = slow->next;
        }
        ListNode* tmp=slow->next;
        slow->next = tmp->next;
        delete tmp;
        return dummyHead->next;
    }
};
```
这个解法首先定义了一个虚拟头节点，然后然后快慢两个指针指向它。

我们想要删除倒数第n个节点，其实巧思就是先让fast走n步，随后slow和fast同时走，直到fast指向NULL,这时后slow指向的刚好是要删除的节点，因为slow和fast距离一直为n，所以说fast在最后，slow就在倒数第n个节点处。

但是我们要删除倒数第n个节点，所以我们需要让fast多走一步，fast走n+1步，再让他俩同时走，fast指向NULL的时候slow刚好在要删除节点的上一个节点。
