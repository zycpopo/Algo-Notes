
```c++
#include <vector>
#include <string>
using namespace std;
  
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        vector<string> result;
        // 特殊情况：空输入
        if (digits.empty()) {
            return result;
        }
  
        // 数字到字母的映射（索引0和1不用）
        vector<string> mapping = {
            "",     // 0
            "",     // 1
            "abc",  // 2
            "def",  // 3
            "ghi",  // 4
            "jkl",  // 5
            "mno",  // 6
            "pqrs", // 7
            "tuv",  // 8
            "wxyz"  // 9
        };
  
        string current; // 当前组合
        backtrack(digits, 0, current, mapping, result);
  
        return result;
    }
  
private:
    void backtrack(const string& digits, int index, string& current,
                   const vector<string>& mapping, vector<string>& result) {
        // 递归终止：已经处理完所有数字
        if (index == digits.length()) {
            result.push_back(current);
            return;
        }
  
        // 当前数字对应的字母
        char digit = digits[index];
        string letters = mapping[digit - '0'];
  
        // 遍历当前数字对应的每一个字母
        for (char c : letters) {
            current.push_back(c);           // 做选择
            backtrack(digits, index + 1, current, mapping, result); // 递归
            current.pop_back();             // 撤销选择（回溯）
        }
    }
};
```
### 核心思想：回溯算法（Backtracking）

这道题的本质是**组合问题**：每个数字对应多个字母，我们需要从每个数字的字母集合中选一个，组合成完整的字符串。

**为什么用回溯？**
- 需要尝试所有可能的组合
- 每个数字的选择会影响后续的选择
- 当某个路径探索完所有可能性后，需要回退到上一步尝试其他选择

**回溯三要素：**
1. **路径（path）**：已经选择的字母组合
2. **选择列表**：当前数字对应的所有字母
3. **终止条件**：路径长度 == 数字串长度
### 执行过程图解（以 "23" 为例）
```text
递归树：
                   " "
         /          |          \
        a           b           c        ← 数字2: abc
      / | \       / | \       / | \
     d  e  f     d  e  f     d  e  f     ← 数字3: def
     |  |  |     |  |  |     |  |  |
    ad ae af    bd be bf    cd ce cf     ← 结果

路径变化：
"" → "a" → "ad" → 记录 "ad"
              → "ae" → 记录 "ae"
              → "af" → 记录 "af"
    → "b" → "bd" → 记录 "bd"
              → "be" → 记录 "be"
              → "bf" → 记录 "bf"
    → "c" → "cd" → 记录 "cd"
              → "ce" → 记录 "ce"
              → "cf" → 记录 "cf"
```
### 时间复杂度
- **O(3^m × 4^n)**，其中：
    - m = 映射为3个字母的数字个数（2,3,4,5,6,8）
    - n = 映射为4个字母的数字个数（7,9）
- 每个组合需要 O(L) 时间构建（L = 数字串长度）
- 总时间 = O(L × 3^m × 4^n)
### 空间复杂度
- **O(3^m × 4^n)**：存储所有结果
- 递归栈深度为 O(L)
- 不计结果空间，额外空间为 O(L)
### 回溯算法模板
```c++
void backtrack(路径, 选择列表) {
    if (满足终止条件) {
        记录结果;
        return;
    }
    
    for (选择 in 选择列表) {
        做选择;
        backtrack(路径, 新的选择列表);
        撤销选择;  // 回溯核心
    }
}
```
