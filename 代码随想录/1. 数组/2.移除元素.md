[27. 移除元素 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-element/description/)
## 暴力解法：
就是直接将目标值删去，然后让它后面的值依次向前覆盖。
``` c++
// 时间复杂度：O(n^2)
// 空间复杂度：O(1)
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int size = nums.size();
        for (int i = 0; i < size; i++) {
            if (nums[i] == val) { // 发现需要移除的元素，就将数组集体向前移动一位
                for (int j = i + 1; j < size; j++) {
                    nums[j - 1] = nums[j];
                }
                i--; // 因为下标i以后的数值都向前移动了一位，所以i也向前移动一位
                size--; // 此时数组的大小-1
            }
        }
        return size;

    }
};
```
## 双指针法：
利用快慢指针，实现让他俩在一个循环里面同时工作。
定义快慢指针：
- 快指针：寻找新数组的元素 ，新数组就是不含有目标元素的数组
- 慢指针：指向更新 新数组下标的位置
```c++
// 时间复杂度：O(n)
// 空间复杂度：O(1)
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int left=0;
        int right=0;
        while(right<nums.size()){
            if(val!=nums[right]){
                nums[left++]=nums[right];
            }
            right++;
        }
        return left;
    }
};
```
我这里的写法有点简陋，不过思想绝对是正确的，代码中left就代表慢指针，right代表快指针。
循环里面分两种情况，一个就是还没遇到目标值，这时候，left和right就是稳步推进，之间的距离并没有变化。但是一旦碰到目标值，就只有right移动，这样子，下次就直接把目标值原本的位置用新的right值覆盖了。
这样子不仅解决了问题，还将时间复杂度变为了O(n)。
