[101. 对称二叉树 - 力扣（LeetCode）](https://leetcode.cn/problems/symmetric-tree/description/?envType=study-plan-v2&envId=top-100-liked)

```c++
class Solution {
public:
    bool compare(TreeNode* left, TreeNode* right) {
        // 首先排除空节点的情况
        if (left == NULL && right != NULL) return false;
        else if (left != NULL && right == NULL) return false;
        else if (left == NULL && right == NULL) return true;
        // 排除了空节点，再排除数值不相同的情况
        else if (left->val != right->val) return false;

        // 此时就是：左右节点都不为空，且数值相同的情况
        // 此时才做递归，做下一层的判断
        bool outside = compare(left->left, right->right);   // 左子树：左、 右子树：右
        bool inside = compare(left->right, right->left);    // 左子树：右、 右子树：左
        bool isSame = outside && inside;                    // 左子树：中、 右子树：中 （逻辑处理）
        return isSame;

    }
    bool isSymmetric(TreeNode* root) {
        if (root == NULL) return true;
        return compare(root->left, root->right);
    }
};
```
### 核心思想

**对称 ≠ 同一个节点的左右孩子相等**，而是**「镜像位置」的两个节点相等**。
因此，我们需要自定义一个递归函数 `compare(left, right)`，专门比较以 `left` 和 `right` 为根的两棵子树是否互为镜像。

### 递归的终止条件（先排错，再深入）

递归的精髓在于：**先处理所有「不对称」和「到底」的情况，剩下的就是「值相等，需要继续往下比」的情况**。

表格

|条件|含义|返回值|
|:--|:--|:--|
|`left == NULL && right != NULL`|左空右不空，结构不对称|`false`|
|`left != NULL && right == NULL`|左不空右空，结构不对称|`false`|
|`left == NULL && right == NULL`|都为空，到底了，对称|`true`|
|`left->val != right->val`|都不空但值不等，不对称|`false`|

**注意判断顺序**：必须先判断空指针，再判断值。如果反过来，当节点为空时访问 `val` 会导致**空指针异常**。

### 递归的递推逻辑（外侧 + 内侧）

当四个终止条件都没触发时，说明：
- 左右节点都不为空
- 左右节点的值相等

但这**只代表当前这一层对称**，下面的子树还需要继续验证：

```cpp
bool outside = compare(left->left, right->right);  // 外侧：左子树的左 vs 右子树的右
bool inside  = compare(left->right, right->left);  // 内侧：左子树的右 vs 右子树的左
return outside && inside;
```

只有**外侧对称且内侧对称**，当前这对节点才最终对称。
## 四、关键点 & 易错点

### 1. 为什么值相等不直接返回 `true`？

**值相等只是「必要条件」，不是「充分条件」**。

例如下面这棵树，根节点的左右孩子值都是 2，但子树明显不对称：
```plain
    2              2
   /                \
  3                  4
```
如果写成：
```cpp
else if (left->val == right->val) return true;  // ❌ 错误！
```

就会只检查了当前一层，忽略了下面的子树，导致误判。

### 2. 为什么 `compare` 的参数是 `left->left` vs `right->right`？

因为比较的是**镜像位置**，不是同一棵子树内部：

```plain
        left 子树              right 子树
           2                      2
          / \                    / \
    [外侧]3   4[内侧]      [内侧]4   3[外侧]
```
- **外侧**：`left->left` 对比 `right->right`（远离中心）
- **内侧**：`left->right` 对比 `right->left`（靠近中心）
### 3. 终止条件的顺序不能乱

必须先判断空指针，再判断值。否则当 `left` 或 `right` 为 `NULL` 时，`left->val` 会触发**运行时错误**。

## 五、复杂度分析

- **时间复杂度**：O(n) ，每个节点最多被访问一次。
- **空间复杂度**：O(h) ，其中 h 为树的高度。递归栈的深度取决于树的高度，最坏情况下（退化为链表）为 O(n) 。
