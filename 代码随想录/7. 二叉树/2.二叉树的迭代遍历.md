## 前序遍历
```c++
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
	    stack<TreeNode*> st;
	    vector<int> result;
	    if(root == NULL) return result;
	    st.push(root);
	    while(!st.empty()){
		    TreeNode* node = st.top();
		    st.pop();
		    result.push_back(node->val);
		    if(node->right) st.push(node->right);
		    if(node->left)  st.push(node->left);
	    }
	    return result;
    }
};
```
前序遍历的顺序是：**根 → 左 → 右**。递归写法很直观，但迭代写法需要借助栈来模拟递归的调用过程。
核心思想是：**每访问一个节点，先记录它的值，然后优先将右子节点入栈，再将左子节点入栈**。因为栈是后进先出（LIFO），这样出栈时左子节点会先被处理，从而保证遍历顺序为「根左右」。

|要点|说明|
|:--|:--|
|**入栈顺序**|先 `right` 后 `left`，因为栈是 LIFO，这样出栈时才是左先右后|
|**访问时机**|节点出栈时立即访问（记录值），对应前序「根」在最前|
|**空树处理**|提前判断 `root == NULL`，避免空指针入栈|

### 复杂度分析
- **时间复杂度**：O(n) ，每个节点恰好入栈、出栈一次。
- **空间复杂度**：O(n) ，栈的最大深度取决于树的高度，最坏情况下（退化为链表）为 O(n) 。

## 中序遍历
```c++
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
		stack<TreeNode*> st;
		vector<int> result;
		TreeNode* cur = root;
		while(cur!=NULL || !st.empty()){
			if(cur != NULL){
				st.push(cur);
				cur = cur->left;
			}
			else{
				cur = st.top();
				st.pop();
				result.push_back(cur->val);
				cur = cur->right;
			}
		}
		return result;
    }
};
```
中序遍历的顺序是：**左 → 根 → 右**。与前序不同，中序遍历时不能立即访问根节点，而需要先处理完左子树。
核心思想是：**沿着左子树一路向下，将沿途节点全部入栈；当走到尽头时，弹出栈顶节点（此时该节点的左子树已处理完毕），访问它，然后转向右子树**。右子树再重复同样的过程。

|要点|说明|
|:--|:--|
|**循环条件**|`cur != NULL \| !st.empty()`，两者都必须为空才算遍历结束|
|**左子树优先**|`cur` 不为空时一直往左走并入栈，直到为空|
|**访问时机**|节点出栈时访问，此时它的左子树已全部处理完毕|
|**转向右子树**|访问完当前节点后，`cur = cur->right`，继续处理右子树|

### 复杂度分析
- **时间复杂度**：O(n) ，每个节点恰好入栈、出栈一次。
- **空间复杂度**：O(n) ，栈的最大深度为树的高度。

## 后序遍历
```c++
class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
	    stack<TreeNode*> st;
	    vector<int> result;
	    if(root == NULL) return result;
	    st.push(root);
	    while(!st.empty()){
		    TreeNode* node = st.top();
		    st.pop();
		    result.push_back(node->val);
		    if(node->left)  st.push(node->left);
		    if(node->right) st.push(node->right);
	    }
	    result.reverse(result.begin(),result.end());
	    return result;
    }
};
```
后序遍历的顺序是：**左 → 右 → 根**。直接模拟后序遍历的迭代写法较为复杂，因为需要判断右子树是否已经访问过。

这里采用一种**巧妙的方法**：
- 前序遍历是「根左右」；
- 如果调整入栈顺序为「根右左」（先左后右入栈），得到的结果是「根右左」；
- 将「根右左」的结果反转，正好得到「左右根」，即后序遍历!

|要点|说明|
|:--|:--|
|**入栈顺序**|先 `left` 后 `right`，这样出栈顺序是「根右左」|
|**反转操作**|`reverse` 将「根右左」变为「左右根」，即后序|
|**核心思想**|利用前序遍历的变形 + 反转，避免复杂的标记判断|
### 复杂度分析
- **时间复杂度**：O(n) ，每个节点入栈出栈一次，反转结果需要 O(n) 。
- **空间复杂度**：O(n) ，栈空间和结果数组的空间。
